# Guidelines Document Template

Section order for the produced guide. Every identity rule carries a pass/fail pair.
Length target: substantive but holdable, roughly 120-200 lines for the core guide;
channel playbooks extend it only if the user asked for them.

1. **Header.** Brand, version, date, the maintenance rule, and the gate precedence
   note (AI-tells gate runs first and wins on conflict; conflicts get named).
2. **Who we are when we write.** One paragraph of identity in the brand's own terms,
   plus archetype position stated as "between X and Y, borrowing Z for [register],
   never W."
3. **Who reads us.** Reader profile and the moments they meet the writing, with the
   consequences for the copy stated as rules (e.g. "pays off within two sentences").
4. **Voice pillars.** Three to five, constant across surfaces, each with one
   imperative rule and a yes/no example pair. Adjectives without examples are
   unfinished.
5. **Humor.** Setting, kind, banned surfaces, and the tiebreak ("when unsure, keep a
   straight face" or the brand's equivalent).
6. **Self-reference.** The pronoun rule and its boundaries.
7. **Tone by reader state.** A table: reader state, surfaces, tone. Followed by the
   governing principle extracted from edge cases, stated as a rule the AI can apply
   to unsampled situations.
8. **Register by deliverable.** Each register's ceiling, calibrated from Phase 2
   picks, with what is welcome and what is banned in each.
9. **House style.** The ratified parameter list from Phase 3.
10. **Anti-models.** The named failure directions from the cringe list, each with
    what the brand does instead, plus the AI voice as the standing third anti-model.
11. **Before/after.** At least one full rewrite pair with the diagnosis named.
12. **Verification loop.** The v1 shipping note and the correction-to-rule
    maintenance process.

## Encoding note

Offer two output formats: a markdown guide for knowledge bases (Notion, GitHub,
Obsidian) and a companion skill whose SKILL.md is an operational distillation
(pillars, tone table, tiebreakers, hard rules) with the full guide as a reference
file. Progressive disclosure beats a monolith: an 8,000-word single file degrades
compliance because everything competes for attention.
